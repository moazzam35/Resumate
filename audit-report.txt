2. CRITICAL / MAJOR BUGS FOUND
================================================================================
[Server — highest impact]
1. ReferenceError in 4 AI route catch blocks
   Files: app/api/ai/route.js:26/100, app/api/ats-score/route.js:96/271,
          app/api/ats-improve/route.js:52/171, app/api/job-match/route.js:119/246
   `const userId = auth?.userId` is declared inside the try block but referenced
   inside the catch block. Any failure throws ReferenceError before the AI-credit
   refund, error log, or intended 500 response executes. Users are charged AI
   credits for failed calls and get generic 500s.

2. Non-atomic version restore
   File: app/api/resumes/[id]/version/[versionId]/route.js
   Safety snapshot, deletion of all 8 sub-resources, and re-creation run in
   separate transactions; a mid-sequence failure permanently deletes resume sections.

3. Cookie token parsing bug
   File: lib/auth.js:79
   Regex /token=([^;]+)/ can match the substring inside `refreshToken=...`, so the
   wrong token can be accepted as the access token.

4. /api/ai type not validated
   File: app/api/ai/route.js:52-60
   Arbitrary `type` values can be written into the Prisma AIType enum (enum
   violation) and produce unhelpful 500s instead of a clean 422.

5. Admin "view resume" navigates to a 404 route
   File: app/admin/resumes/page-content.js:253 — uses /resumes/{id}; correct route is /resume/{id}.

6. Cover letters can never be reopened/edited from the UI
   File: app/dashboard/cover-letters/page-content.js:232 — always links /cover-letter/new,
   ignoring the record id, even though PUT /api/cover-letters/:id exists.

7. Admin settings false success
   File: app/admin/settings/page-content.js:87 — shows "Saved!" without checking res.ok.

8. Admin dashboard blank on failure
   File: app/admin/page-content.js:61 — Promise.all has no .catch and no res.ok check;
   a network error or 401 renders a blank page.

[Client]
9.  Command palette shortcut can never open the palette
    File: components/shared/command-palette.jsx:54 — key listener registered only while open.
10. Hero floating badge overlaps content
    File: components/features/landing/hero.jsx:36 — fixed z-50 badge persists across scroll.
11. Resume preview save timeout unsafe + mobile pagination incomplete
    File: components/features/resume/resume-preview.jsx:135 (no unmount cleanup);
    mobile page toggle only reaches pages 0/1 (pages 3+ unreachable).
12. Touch devices cannot reach action buttons
    Files: components/features/resume/experience-step.jsx:219, projects-step.jsx:97
    (md:opacity-0 md:group-hover:opacity-100 hides buttons on touch devices).
13. Misleading hardcoded badges
    File: app/dashboard/profile/page-content.js:290 — "Pro Architect"/"Verified Account"
    shown for every user regardless of actual plan/email verification.
14. NaN progress ring in Job Match
    File: app/dashboard/job-match/page-content.js:379 — unguarded matchPercentage.
15. Optimistic updates never reverted on failure
    Files: dashboard/notifications, admin/users, admin/ai-usage, components/features/templates/template-gallery.jsx.
16. Timer / abort leaks
    - store/index.js showToast:401 setTimeout race (newer toast cleared early)
    - app/admin/settings/page-content.js: setTimeout with no cleanup
    - components/features/ai/ai-assistant.jsx: clipboard write without catch + 2s copy timer
    - components/features/auth/reset-password-form.jsx:46: redirect timeout, no cleanup
    - app/admin/reports/page-content.js: fabricated-report setTimeout (no cleanup; download button has no onClick)
    - app/dashboard/analytics & app/admin/analytics: no AbortController on date-range changes (stale-response race)
17. Store sync gaps
    - education-step never calls updateEducation; languages-step is local-only;
    - cover-letter/new has unused activeTab state.
18. Fabricated structured data
    File: components/layout/structured-data.jsx — WebApplication aggregateRating reviewCount "50000" is not real.
